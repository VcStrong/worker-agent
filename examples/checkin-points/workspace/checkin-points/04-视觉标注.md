## Token 与规范 <!-- 必填 -->
标注一律用 Token 名，代码里用 `MaterialTheme.colorScheme.*` / `MaterialTheme.typography.*` / `MaterialTheme.shapes.*`；带「新增」的 Token 要进设计系统，不允许在页面里写裸值。

## 组件 <!-- 必填 -->
**复用（M3 原生）**：`Card`、`Button`（Filled）、`Text`、`Icon`、`LazyColumn`、`Divider`/`HorizontalDivider`、`Snackbar`（若项目 toast 用 Snackbar）、`CircularProgressIndicator`、`TopAppBar`。

**新增（进设计系统，待设计系统负责人评审；当前项目没有设计系统库，先放在 `core-ui` 模块并记录）**
| 组件 | 说明 | 状态 |
|---|---|---|
| `CheckinCard`（首页） | 图标 + 标题 + 副标题 + 按钮 | 加载（骨架）、未签、新用户、断签、签到中、已签、确认中、未登录、403、加载失败、无网 |
| `CheckinPanel`（积分页签到区） | 标题 + 刷新说明 + 连签文案 + `CheckinDayRow` + 按钮 | 同上，另有部分失败 |
| `CheckinDayRow` / `CheckinDayCell` | 7 格（字体放大时 4+3）；格子不可点 | 已签、今天未签、今天已签、未到、额外奖励（第 3、7 天，带角标） |
| `CheckinButton` | 统一按钮，首页和积分页共用 | 默认「签到 +N」、未登录「签到」、loading、确认中、已签（禁用）、403（禁用）。成功后「今日已签到」和 403 都是禁用外观，但文案不同 |
| `PointsBalance` | 余额数字 + 缓存提示 | 加载、正常、数值滚动、缓存（带「数据可能不是最新」） |
| `LedgerItem` | 类型 + 时间 + 变动值 | 正数（`success`）、负数（`onSurface`，预留类型）、未知类型 |
| `LedgerFooter` | 列表底部 | 加载中、失败重试、没有更多了 |
| `EmptyState` / `ErrorState` | 插画 / 文案 / 按钮 | 复用于流水空态、整页失败、无网 |
| `Skeleton` | 骨架块 | 签到区、余额、流水行、首页卡片 |

**组件规则**
- 首页和积分页的签到按钮用同一个 `CheckinButton`，不允许两套样式。
- 「今日已签到」不是错误态：用禁用样式，不用 `error` 色。
- 403 说明文字用 `onSurfaceVariant`，不能用 disabled 灰。

## 走查清单 <!-- 必填 -->
开发完成后对照；每项标「通过 / 偏差」，偏差先对照本文 Token 名，再判是设计缺失还是实现偏差（按 rules/arbitration.md 第 2 条）。

**一、Token 与样式**
- [ ] 代码里没有裸色值（#RRGGBB）、裸字号、裸间距，全部走 `MaterialTheme` 和 `spacing.*`、`extendedColors.*`。
- [ ] 颜色：首页卡片未签用 `primaryContainer`，已签用 `surfaceContainerLow`；格子已签 `primary`，今天 `primaryContainer` + 2dp `primary` 边，未到 `surfaceContainerHighest`。
- [ ] 流水 +N 用 `extendedColors.success`，且带「+」号。
- [ ] 字体：余额 `displaySmall`；区块标题 `titleMedium`；格子「第 N 天」`labelSmall`；流水类型 `bodyLarge`、时间 `bodySmall`。
- [ ] 间距：页面边距、卡片 padding 16dp；区块间距 24dp；格子间距 4dp。
- [ ] 圆角：卡片 12dp，格子 8dp，按钮全圆角。

**二、状态覆盖（每个状态都要有截图或录屏）**
- [ ] 首页卡片 11 种：加载、未签、新用户、断签、签到中、已签、确认中、未登录、403、加载失败、无网。
- [ ] 积分页：首次加载、整页失败、部分失败、无网有缓存（带「数据可能不是最新」）、无网无缓存、未登录跳转。
- [ ] 7 天格子：默认、今日已签、周期第 7 天已签（全勾）、第 8 天（只有第 1 天勾）、断签（全未勾）、新用户。
- [ ] 签到按钮：未签、请求中、确认中、已签、403、429 恢复、失败恢复、重复提交。
- [ ] 流水：有数据、空态、翻页加载、翻页失败、没有更多了、预留类型兜底。
- [ ] 成功反馈：toast「签到成功 +N 积分」（N 为 10 / 20 / 40）、按钮切换、勾出现、余额滚动、新流水插入。

**三、文案（逐字对 PRD）**
- [ ] 「签到成功 +N 积分」「今日已签到」「签到结果确认中」「签到失败，请重试」「操作太频繁，请稍后再试」「网络不可用，请检查网络后重试」「账号状态异常，暂无法签到」「连签已中断，今天重新开始」「还没有积分记录」「去签到赚积分」「加载失败，点击重试」「没有更多了」「数据可能不是最新」「每日 0 点（北京时间）刷新」。
- [ ] 流水类型名称：`CHECKIN_BASE` = 「每日签到」，`CHECKIN_STREAK_BONUS` = 「连续签到奖励」。
- [ ] 数值：周期第 1、2、4、5、6 天签到 +10，第 3 天 +20（基础 10 + 奖励 10），第 7 天 +40（基础 10 + 奖励 30）；一个周期合计 110。数值取服务端返回，不在客户端写死。
- [ ] 时间：流水时间按北京时间 yyyy-MM-dd HH:mm，设备时区改动后不变。
- [ ] 余额：千分位，≥ 10,000 不截断。

**四、可访问性**
- [ ] 对比度 ≥ 4.5:1（正文）/ 3:1（大字、图标）：重点检查 `success`、格子角标、已签格子 `onPrimary` 字、403 说明。亮色 / 深色 / 动态取色各测一次。
- [ ] 点击区 ≥ 48dp：签到按钮、卡片、重试、「去签到赚积分」。
- [ ] 系统字体 200%：格子改两行（4+3），余额和按钮不截断，卡片不溢出。
- [ ] TalkBack：格子朗读、按钮朗读、toast live region、流水行合并节点，与交互说明一致。
- [ ] 移除动画开启后，勾、余额滚动、脉冲不播放。
- [ ] 不只靠颜色：已签有勾，今天有边框，额外奖励有角标文字。

**五、适配**
- [ ] 360dp、411dp、折叠屏展开宽度下，格子不挤压、不溢出。
- [ ] 手势导航下列表末尾不被导航条遮挡。
- [ ] 深色模式所有状态可读，插画和空态在深色下可见。
- [ ] 横屏：不要求专门布局，但内容不被裁切。

**六、偏差登记**
- 偏差清单格式：位置 | 设计值（Token 名） | 实际值 | 属于「设计缺失」还是「实现偏差」 | 负责人 | 是否阻塞上线。
- 阻塞上线：状态缺失（任一异常态没做）、文案与 PRD 不一致、对比度或点击区不达标、裸色值。
- 不阻塞：±1dp 的间距差、动效时长 ±100ms，登记后下版本修。
