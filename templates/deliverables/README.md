# 交付物模板（REQ-006）

- 产物写到 `workspace/<需求名>/<阶段序号>-<产物名>.md`，如 `workspace/checkin-points/02-PRD.md`。
- 复制模板后保留第一行 `<!-- template: xx -->`，校验脚本靠它认模板。
- 标 `<!-- 必填 -->` 的节不能为空（只剩「（…）」占位说明也算空）；`python3 scripts/validate.py --deliverable <文件>` 校验，不合格退回负责角色。
- 「引用」节写明引用了哪些上游产物（路径）；起点阶段写「无（起点）」。
- 产物要求英文时，节标题同步翻译，并在第一行注释里保留模板 id（校验按 `<!-- 必填 -->` 标记和节的顺序认）。
